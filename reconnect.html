পুনরায় সংযোগ করুন

PC-তে Chrome/Edge extension দিয়ে Connect করুন। মোবাইলে নিচের official site খুলে CAPTCHA দিয়ে ফল দেখুন; extension ছাড়াই এই browser-এ কার্ড OCR ব্যবহার করতে আগের পৃষ্ঠায় ফিরতে পারেন।

তথ্য সম্পাদনায় ফিরুনOfficial সাইটে ফল দেখুন
PC extension সেটআপ
Extension ZIP ডাউনলোড করে Extract করুন। Chrome/Edge-এর Extensions → Developer mode → Load unpacked দিয়ে extracted extension folder বাছুন। এটি এই GitHub Pages site-এর জন্য তৈরি extension। Site tab reload করে Connect চাপুন।
